# Changelog

## 0.1.0 — 2026-10-14

First public release.

- Full-screen TUI monitor (Textual): CPU, memory, power/battery, processes, network, disk, system tabs.
- Live coding-agent sessions: Claude Code, Codex, opencode (full detail); muse, crush, qwen, aider, gemini (process only).
- Linux and macOS platform layers; static snapshot mode (`mx stat -s`).
- `install.sh` installer (isolated venv, launcher `mx`).
