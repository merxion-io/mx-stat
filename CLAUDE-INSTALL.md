# Инструкция для Claude Code: поставить hstat на эту машину

Ты получил архив `hstat-merxion-*.zip` — готовый инструмент, ничего писать с нуля не нужно.
Задача: установить, проверить, показать пользователю, как запускать.

## Шаги

1. **Распаковать и установить**
   ```sh
   cd ~/Downloads && unzip -o hstat-merxion-*.zip && cd hstat-merxion
   ./install.sh
   ```
   Скрипт копирует код в `~/.local/share/hstat`, создаёт venv (uv → иначе `python3 -m venv`),
   ставит `textual`, `psutil`, `rich` из `requirements.txt` и пишет лаунчер `~/.local/bin/hstat`.
   Нужен Python 3.11+. Если его нет, а есть `uv` — он скачает нужный Python сам.

2. **Проверить PATH.** Если `install.sh` предупредил, что `~/.local/bin` не в PATH:
   ```sh
   echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
   ```
   (или `~/.bashrc`, если оболочка bash). Новую строку не добавляй, если такая уже есть.

3. **Проверить без терминала** (TUI нельзя запускать из неинтерактивного Bash — он зависнет):
   ```sh
   hstat -h
   COLUMNS=120 hstat -s --no-color | head -40
   ~/.local/share/hstat/venv/bin/python tests/smoke_test.py 140 46
   ```
   Первая команда печатает справку, вторая — статичный снимок со всеми секциями, третья
   прощёлкивает все пять вкладок headless и печатает `smoke test OK`. Если все три отработали
   без traceback — установка рабочая.

4. **Сказать пользователю**: запускать `hstat` в терминале (лучше шириной 140+ колонок,
   на 200+ таблица агентов показывает все колонки), `hstat -s` для снимка. Клавиши перечислены
   в `hstat -h`.

## Что не делать

- Не запускай `hstat` без флагов из своего Bash — это полноэкранный TUI, ему нужен TTY.
- Не переписывай код «под себя» до того, как он запустился как есть. Сначала `install.sh`
  и проверка, потом правки по просьбе пользователя.
- Не ставь зависимости в системный Python — только venv, который создаёт `install.sh`.

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| `install.sh: не найден python3` | Поставить `uv` (`brew install uv` / `curl -LsSf https://astral.sh/uv/install.sh \| sh`) и повторить: uv скачает Python сам |
| `hstat -s` работает, агентов 0 | Нормально, если сейчас нет запущенных сессий Claude Code. Агенты появляются из `~/.claude/sessions/*.json` |
| В TUI у агентов `…` вместо контекста первые секунды | Нормально: трекер транскриптов прогревается в фоне |
| Всё на месте, но карточка КОНТЕЙНЕРЫ пустая | Нет OrbStack. Это опционально |
| Не macOS | Инструмент писался под macOS; на Linux запустится, но сеть/диск/батарея будут пустыми. Не обещай пользователю, что всё будет работать, пока не проверил |

## Где что лежит после установки

```
~/.local/bin/hstat              лаунчер (sh → venv python → hstat.py)
~/.local/share/hstat/hstat.py   точка входа
~/.local/share/hstat/core.py    данные + SessionTracker + логотип (LOGO/BRAND/WHITE)
~/.local/share/hstat/tui.py     Textual-приложение
~/.local/share/hstat/snapshot.py режим -s
~/.local/share/hstat/venv/      окружение
```

Подробности про источники данных и грабли macOS — в `README.md` рядом.
